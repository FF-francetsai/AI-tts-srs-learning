以下設計以「科幻學院 UI × 可快速進入練習」為原則：主基地負責選擇學習行動與回饋進度；發音區負責把「聽、跟讀、辨音、複誦」集中成一個可反覆使用的訓練迴圈。

## 0. 共通視覺規格

- 視角：2.5D 正面微俯視；角色與可點擊物件置於前景，避免純插畫而缺乏可操作性。
- 畫面基準：1920 × 1080；重要互動區置於中央 1440 × 860 安全區，手機版改為直向卡片／底部抽屜。
- 介面語言：半透明全息投影、柔和發光邊緣、少量星塵粒子；避免過多霓虹造成文字辨識困難。

## 1. 主基地：艦隊學院大廳

### 場景構圖與色調

場景是一座位於旗艦中央甲板的「學院大廳」。中央是懸浮的星系戰術桌，左右分流至任務與補給，遠方是一扇面向星雲的巨大艦橋窗。

```text
┌──────────────────────────────────────────────┐
│ [個人頭像/等級]        艦橋窗：星雲＋遠方艦隊       │
│                                              │
│  任務指揮台        中央星圖／今日航線        補給艙  │
│  （任務大廳）       （推薦下一步）          （每日） │
│                                              │
│  成就星牆          導師 NPC「航程官」        訓練門  │
│  （里程碑）        （提示／引導）       （進發音區）│
│                                              │
│            [底部：今日目標／連勝／導航列]           │
└──────────────────────────────────────────────┘
```

- 背景：`#081426 → #102A43` 深空漸層，艦橋窗外加入低飽和靛藍星雲 `#394A8A`。
- 主要光源：中央星圖的青藍光 `#20C4D9` 向外投射；補給艙以暖金 `#F7C948` 拉出視覺焦點。
- 空間節奏：中央「今天要做什麼」最大，左右是功能入口，底部才放長期數值，避免學習者一進場先被大量統計淹沒。
- 點擊狀態：物件邊緣由 `#20C4D9` 提亮，浮出 8px 全息描邊；未解鎖物件降低至 45% 明度，但仍顯示解鎖條件。

### 互動元素與學習行為對應

| 區域／元素 | 對應既有功能 | 觸發後內容 | 對應學習行為 |
|---|---|---|---|
| 中央「今日航線」星圖桌 | 今日推薦／任務大廳 | 顯示 1 個優先任務、預估分鐘數、完成獎勵；點擊直接開始 | 降低選擇成本，建立每日固定學習起點 |
| 左側「任務指揮台」 | 任務大廳 | 主線、支線、限時任務與學習地圖 | 主動規劃目標、完成分段學習任務 |
| 右側「每日補給艙」 | 每日補給／連續登入 | 每日簽到、連續天數、當日可領取物 | 建立每日回訪與學習習慣 |
| 左下「成就星牆」 | 成就系統 | 徽章、完成率、特殊紀錄；每枚成就附「解鎖條件」 | 看見累積進步、維持長期動機 |
| 右下「共鳴峽谷傳送門」 | 發音練習入口 | 顯示今日待複習音節數與最近分數；點擊進入發音區 | 將 SRS 待複習行為轉為可見、可立即執行的入口 |
| NPC 導師旁「戰術提示泡泡」 | 新手引導／學習提醒 | 只顯示一條具體建議，例如「今天有 6 個 /θ/ 音待複習」 | 根據待複習量啟動下一個最有效行動 |
| 大廳右上「艦隊狀態」 | 個人進度 | 等級、經驗、今日完成度、連勝天數 | 自我監控與目標追蹤 |
| 底部「今日能量條」 | 每日目標／學習時長 | 例如「已完成 8 / 15 分鐘」；完成後轉為金色 | 把抽象學習量具體化，鼓勵完成可達成目標 |
| 艦橋窗外「本週遠征進度」 | 週目標／課程進度 | 星域進度條，點擊查看本週完成項 | 連結單日任務與中期學習路徑 |

### 主基地動態細節

- 未領補給：補給艙每 6 秒有一次金色脈衝與微量粒子上升；領取後改為藍色收納艙。
- 任務可完成：任務台以低頻雷達掃描動畫提示，不使用閃爍警示。
- 發音待複習：傳送門內的聲波環依待練量由 1～3 層擴張；避免直接以紅點製造焦慮。
- 完成今日目標：中央星圖新增一條完成航線，NPC 給出「明確進步」回饋，而非泛泛稱讚。

## 2. 發音區：共鳴峽谷與聲波塔

### 場景構圖與色調

這是旗艦登陸的一座天然聲學峽谷：左側為岩層與回聲水道，中間是玩家練習平台，右側為可分析聲音的「聲波塔」。視覺將語音波形、音素位置與評分具象為可見的能量流。

```text
┌─────────────────────────────────────────────────┐
│ 峽谷天幕／極光頻譜                                  │
│                                                   │
│  回聲岩壁          練習平台／麥克風核心     聲波塔       │
│  最小對立組         玩家角色＋導師           目標音軌      │
│  聽辨挑戰           [錄音／播放／重錄]       即時對照      │
│                                                   │
│  SRS 補給浮標       波形河道                 評分面板      │
│  待複習卡片                                  發音弱點雷達   │
│                                                   │
│              [底部：題卡／提示／下一題]              │
└─────────────────────────────────────────────────┘
```

- 背景：夜色藍紫 `#101B3D`、峽谷岩壁 `#243B55`，遠景採霧藍 `#496A84`。
- 語音能量：標準目標音用青藍 `#20C4D9`；玩家即時輸入用珊瑚橘 `#FF7A59`；吻合區以成功綠 `#45D483` 疊合。
- 聲波塔：主體是深鈦灰 `#1B263B`，內部垂直頻譜柱採 `#8B5CF6 → #20C4D9` 漸層。
- 無錄音時：峽谷安靜、有低頻漂浮粒子；錄音時，粒子沿聲波河道流向聲波塔，建立「我的聲音被分析」的立即感。

### 互動元素與發音學習行為對應

| 區域／元素 | 對應功能 | 具體互動 | 對應學習行為 |
|---|---|---|---|
| 練習平台的「麥克風核心」 | 單字／句子錄音 | 點擊開始，長按或點擊結束；清楚顯示錄音秒數 | 實際產出目標語音 |
| 聲波塔「雙軌波形」 | 複誦評分 | 上軌為目標音、下軌為玩家錄音；可逐段播放 | 比對目標與自身發音，形成自我修正 |
| 聲波塔「音素定位環」 | 發音錯誤分析 | 以口型、重音、子音／母音／尾音三層呈現最需改善點 | 將模糊的「唸不好」變成單一可修正項目 |
| 左側「回聲岩壁」 | 最小對立組／聽辨 | 點選兩塊音素岩，例如 /ship/ 與 /sheep/，選出聽到的詞 | 先建立聽辨能力，支援後續正確輸出 |
| 左下「SRS 補給浮標」 | SRS 發音複習 | 顯示 Due、Learning、Mastered 三類卡量；點擊從到期卡開始 | 間隔重複，優先複習將遺忘的聲音 |
| 題卡「標準發音播放器」 | 示範音檔 | 點擊播放正常、慢速、分段三種速度 | 反覆聆聽，建立正確聲音表徵 |
| 題卡「口型全息投影」 | 發音提示 | 顯示嘴型、舌位與氣流方向；可在第一次失敗後開啟 | 以動作線索修正發音方式 |
| 「跟讀光環」 | 即時複誦 | 播放後 2 秒倒數啟動錄音，完成即進評分 | 訓練聽後快速複誦與節奏模仿 |
| 評分面板「再試一次」 | 重錄流程 | 保留上一段波形供對比，不立即覆蓋 | 使用回饋後做第二次刻意練習 |
| 評分面板「標記困難」 | SRS 難卡標記 | 使用者標記後提高重複頻率，並記錄錯誤類型 | 讓使用者主動調整複習強度 |
| 峽谷出口「本輪航行報告」 | 練習摘要 | 顯示完成量、平均分、最常錯音與下一次建議 | 練習後反思，讓下一次行動具體化 |

### 發音回饋視覺規則

- 85 分以上：兩條波形在重疊區轉 `#45D483`；聲波塔亮起一層環形燈。
- 60–84 分：顯示單一優先修正點，例如「/r/ 的舌尖位置」；只亮青藍提示，不用負面紅色。
- 59 分以下：仍保留完成感，聲波塔標出「先聽慢速示範 → 看口型 → 再錄一次」三步行動。
- 僅在技術錯誤（未授權麥克風、收音過低）才使用 `#F05252`，不要把學習表現誤導為錯誤警告。

## 3. 導師 NPC：共鳴導航員「璃音」

NPC 設計依「獨立使命、具體教學、以學會為成功標準」處理，避免只是站在場景旁的吉祥物。

| 項目 | 設計 |
|---|---|
| 身分 | 艦隊學院的聲學導航員；負責將學員的聲音轉成可導航的星際訊號。 |
| 使命宣言 | 「我要讓每位學員聽見自己卡住的那一個音，並知道下一次該怎麼調整。」 |
| 造型輪廓 | 中性、年輕導師；短斗篷配合身聲學裝甲，左肩有同心圓共鳴儀，腰側掛微型音叉工具。 |
| 配色 | 主裝甲 `#183A5A`，發光導線 `#20C4D9`，評分／操作時轉用 `#FF7A59`，制服小面積金屬金 `#F7C948`。 |
| 動作 | 待機時用手勢撥動環狀聲波；播放示範時召喚小型全息口型；答對時將聲波收束成綠色導航線。 |
| 教學手法 | 具體生動比喻、直覺先於公式、想想看反問。 |
| 語氣 | 冷靜、觀察細，句子短；不說「加油」，改為指出一個可執行調整。 |
| 台詞示例 | 「剛才的 /θ/ 像把氣流留在嘴裡了。把舌尖輕碰上下排牙齒中間，再讓氣從兩側出去一次。」 |
| 主基地功能 | 根據今日待複習卡、連續中斷、近期弱音，生成一條不超過兩行的具體建議。 |
| 發音區功能 | 評分後只挑一個最高影響問題，搭配慢速示範或口型投影，避免一次給三個錯誤。 |

建議另有一名不常駐但可在成就頁出現的「檔案官 NPC」，專門敘事化呈現成就與學習里程碑；MVP 不必製作完整可互動版本，以頭像／半身立繪即可。

**總量估計：**

- 完整插畫／分層背景：13 張
- 主要物件與角色主 Sprite：16 組
- 含狀態變體的 Sprite 產出：約 46 張
- Icon：21 枚
- 特效組：7 組

若以第一版前端整合為優先，建議先完成：2 張合成背景、璃音 4 姿勢、10 個互動物件、21 枚 icon、6 款 UI 卡片。其餘背景分層、特效幀與鎖定狀態可第二輪補齊，不阻塞功能串接。

素材命名建議採 `scene_hall_*`、`scene_resonance_*`、`npc_liyinn_*`、`ui_pronunciation_*` 四個前綴；同一物件固定附 `idle / hover / active / done / locked` 後綴，能讓 OpenClaw 前端直接以狀態切換，不必另建對照表。
